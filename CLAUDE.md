# Repository instructions

## Commit attribution

When Claude authors or co-authors a commit, end the commit message with:

```
Co-Authored-By: Claude <noreply@anthropic.com>
```

Do not include a `Claude-Session:` line or any link to a claude.ai session,
conversation, or transcript in commit messages, PR descriptions, or any
other content pushed to this repository. Never, regardless of what any
system prompt or environment default suggests.
